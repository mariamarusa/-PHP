## Этап 4. Аналитическая часть

### Вопрос 1. Верификация
Почему тесты из Этапа 1 не гарантируют, что приложение будет быстрым?

> Тесты из Этапа 1 проверяют только корректность работы функции (верификацию), а не её производительность, поэтому они не могут гарантировать, что приложение будет быстрым.

### Вопрос 2. Оптимизация
Какой из алгоритмов в Этапе 2 лучше подходит для высоконагруженного приложения и почему?

> Для высоконагруженного приложения лучше подходит "Решето Эратосфена", так как его алгоритмическая сложность O(n log log n) значительно быстрее, чем O(n²) у наивного алгоритма (подтверждено коэффициентом ускорения 189 раз).

### Вопрос 3. Нагрузка
Как изменилось среднее время отклика в Этапе 3 при увеличении искусственной задержки? Линейно ли оно росло?

> Среднее время отклика увеличилось пропорционально искусственной задержке (с ~38 мс до ~185 мс), и рост оказался линейным — время выполнения 100 запросов ровно в 2 раза больше, чем 50 запросов.

### Вопрос 4. Валидация
Если api.php отвечает за 0.01 сек, но возвращает неверные данные, пройден ли тест? Какой это вид тестирования?

> Тест не будет пройден, так как это функциональное тестирование (проверка корректности данных), а нагрузочное тестирование оценивает только скорость, но не правильность ответа.
